# Acute By — public web pages (GitHub Pages)

Host this `docs/` folder as your developer website (free):

1. Create a GitHub repository named **`acuteby.github.io`** (use your GitHub username in place of `acuteby` if different).
2. Copy the contents of this folder into the repository root and push. The site is live at `https://acuteby.github.io/` within a few minutes.
3. URLs to use in Play Console / AdMob:
   - Website: `https://acuteby.github.io/`
   - Jarlings privacy policy: `https://acuteby.github.io/jarlings/privacy.html`
   - app-ads.txt: `https://acuteby.github.io/app-ads.txt` (**must be at the root of the developer website** listed on the Play listing)
4. After you create the AdMob account, replace `pub-0000000000000000` in `app-ads.txt` with your publisher ID (AdMob → Apps → View all apps → app-ads.txt → "How to set up").

If your GitHub username isn't `acuteby`, update `privacy.url` in each game's `secrets.properties` and the store listing.
